Bagian 1
Apa Itu NetGuard Monit?
Sebuah aplikasi monitoring jaringan LAN berbasis web yang dirancang khusus untuk MikroTik RouterOS. Hadir sebagai alternatif ringan dan self-hosted terhadap solusi monitoring perusahaan seperti PRTG.

Dasar Pengembangan

Backend dibangun dengan Python (FastAPI), basis data waktu-deret menggunakan SQLite, dan frontend visualisasi dengan Chart.js. Template halaman menggunakan Jinja2.

Target Pengguna

Administrator jaringan, teknisi ISP, dan pengelola jaringan kecil hingga menengah yang memantau perangkat MikroTik melalui jaringan LAN privat.

Bagian 2
Kegunaan & Fungsi Utama
NetGuard Monit memantau kesehatan dan performa jaringan LAN secara real-time, memberikan peringatan awal terhadap gangguan, dan menyimpan histori lalu lintas untuk analisis kemudian.

Trafik Antarmuka

Pantau RX/TX bits per detik pada setiap antarmuka MikroTik (ether, bridge, wlan, sfp) dengan granularitas detik, menit, jam, hari, dan bulan.

Link UP/DOWN

Deteksi status router dan WAN interface. Munculkan alert saat router terputus atau WAN mati, dengan indikator visual hijau/merah di dashboard.

Ping & Latency

Kumpulkan ICMP latency (min/avg/max) dan packet loss per target. Grafik PingPlotter-style dengan zona pengisian antara min dan max latency.

Deteksi DDoS

Analisis baseline lalu lintas untuk mendeteksi lonjakan trafik anomali yang mungkin merupakan serangan DDoS atau broadcast storm.

RouterOS Health

Pantau beban CPU, penyimpanan befas, versi RouterOS, dan nama papan sirkuit (board name) dari sistem router.

Alert & Notifikasi

Sistem peringatan berbasis ambang batas (threshold) dengan cooldown. Dukungan notifikasi Telegram untuk alert critical dan warning.

Kartu Metrik Kesehatan

  • Penyimpanan befas / total

Tampilan Dashboard Slide 4 / 9
Fitur Utama
Grafik Trafik Antarmuka
Visualisasi lalu lintas masuk (RX) dan keluar (TX) dalam bits per detik, dengan kontrol penuh atas granularitas dan rentang waktu. Data disimpan per 5 detik untuk resolusi real-time.

Granularitas Waktu

  • Detik (real-time) — data setiap 5 detik, cocok untuk pemantauan lonjakan lalu lintas seketik.
  • Menit — agregasi per menit untuk analisis harian.
  • Jam — agregasi per jam untuk analisis mingguan.
  • Hari / Bulan — agregasi untuk histori jangka panjang.

Rentang Waktu

  • 1 jam
  • 6 jam
  • 24 jam
  • 3 hari
  • 1 minggu

Semua rentang otomatis disesuaikan zona waktu WIB.

Tampilan Label X-Axis

  • Format HH:MM:SS (jam:menit:detik)
  • Auto-skip untuk menghindari tumpang tindih label
  • Rotasi 45° untuk keterbacaan
  • Font mengecil otomatis pada granularitas Detik
  • Sinkron dengan waktu live clock & kartu status

Fitur Utama
Ping & Latency Monitoring
Pantau kualitas koneksi ke target eksternal (mis. 8.8.8.8, 1.1.1.1) dan internal melalui protokol ICMP. Cocok untuk deteksi gangguan konektivitas dan degradasi jaringan.

Metrik yang Dikumpulkan

  • Min latency (ms)
  • Avg latency (ms)
  • Max latency (ms)
  • Packet loss persen (%)
  • Paket terkirim & diterima
  • Waktu observasi (WIB)

Grafik PingPlotter-style

  • Lini hijau: rata-rata latency
  • Lini biru putus: minimum latency
  • Lini oranye putus: maksimum latency
  • Lini merah putus: packet loss (sumbu kanan)
  • Zona pengisian (fill) antara min & max latency
  • Selector target ping multi-target

Alert Ping

  • Ambang batas latency (ms)
  • Ambang batas packet loss (%)
  • Alert otomatis saat melebihi threshold
  • Notifikasi Telegram (opsional)

Sinkronisasi Waktu

Semua stempel waktu grafik ping menggunakan zona WIB (GMT+0700) yang sama dengan grafik trafik, live clock, dan kartu status. Tidak ada selisih waktu antar panel.

Arsitektur
Keamanan & Deployment
Didesain untuk deployment aman di jaringan privat tanpa mengekspos port ke internet publik. Akses eksternal hanya melalui satu jalur: Cloudflare Tunnel.

Model Keamanan

  • Tidak ada port Docker yang dipublish ke publik
  • Akses eksternal hanya lewat Cloudflare Tunnel (ingress tunggal)
  • RouterOS REST hanya reachable dari jaringan LAN
  • Secrets (password, token) disimpan di .env (tidak di version control)
  • Autentikasi session dengan CSRF protection
  • Security headers: CSP, HSTS, X-Frame-Options, X-Content-Type-Options, Permissions-Policy
  • Validasi ketat pada semua environment variable saat startup

Deployment Docker

  • Docker + Docker Compose
  • cap_add: NET_RAW untuk mengizinkan ICMP ping dari container
  • iputils-ping terinstal di dalam container
  • Penyimpanan data SQLite di volume ./data
  • restart: always — container otomatis nyala kembali setelah reboot
  • Build image dengan Python 3.13 slim

Ringkasan
Ringkasan Aplikasi
NetGuard Monit adalah solusi monitoring jaringan LAN yang ringan, aman, dan self-hosted untuk MikroTik RouterOS, cocok untuk pengawasan jaringan kecil hingga menengah.

Aplikasi

Web-based monitoring dengan FastAPI backend, SQLite database waktu-deret, dan Chart.js frontend. Docker-based untuk deployment mudah dan konsisten di berbagai lingkungan.

Kegunaan

Pantau trafik RX/TX, status link router & WAN, latency & packet loss ping, CPU & disk router, serta deteksi DDoS. Dilengkapi sistem alert berbasis threshold dan notifikasi Telegram.

Tampilan

Dark theme modern, grafik time-series dengan waktu sinkron WIB (GMT+0700), dashboard interaktif dengan selector granularitas dan rentang waktu, serta status indikator visual real-time.
